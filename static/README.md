# 静态资源目录

代码里所有图片引用都做了加载失败降级（emoji + 配色兜底），
所以**图片没到位也不会破版**，可以先跑起来再补素材。

## 目录结构

```
static/
├── home/            首页贴纸（4 张，你已有）
│   ├── earth.png            星云地球 —— 家长首页顶部背景 / 儿童首页底部星球
│   ├── star-learning.png    黄色星星「学习」—— 家长首页"开始训练"
│   ├── star-chatting.png    黄色星星「对话」—— 家长首页"陪练介入"
│   └── moon-flower.png      月亮花 —— 家长首页"训练记录"
│
└── scenarios/       情境场景图（2 张，待补）
    ├── build_blocks.png     加入搭积木
    └── outdoor_needs.png    户外休息与需求表达
```

文件名和后端情境 id 一致。后端 `config/scenarios.json` 里写的是 `images/scene_build_blocks.png`，
但后端不提供图片服务，所以图放在前端本地，路径在 `config/scenarios.js` 的 `cover` 里配。
后端以后新增情境，在那里加一项、在这里放一张图即可。

## 场景图规格建议

| 项目 | 建议值 | 原因 |
| --- | --- | --- |
| 尺寸 | 750×560 px | 情境选择页卡片 200rpx 高，介绍页 420rpx 高，按 2x 出图 |
| 格式 | png（文件名已按 png 配） | 想用 jpg 的话同步改 `config/scenarios.js` 里的 cover；小程序主包限 2MB |
| 单张体积 | < 80 KB | 留足主包空间 |
| 风格 | 低饱和、无强对比、构图简单 | 项目书 5.4：低刺激视觉，避免高饱和与密集元素 |
| 内容 | 单一主体、背景干净 | ASD 儿童容易被背景细节分散注意力 |

## 关于图片来源

场景图建议用插画而不是实拍照片：

- 实拍照片里的人脸、背景杂物会成为干扰项
- 插画可以精确控制视觉密度和配色
- 避免真实儿童肖像带来的合规问题

配色和 `config/scenarios.js` 里的 `themeColor` 对上：

| 情境 | themeColor | 色名 |
| --- | --- | --- |
| build_blocks | `#f5cd5c` | 暖阳黄 |
| outdoor_needs | `#b9d94a` | 嫩芽绿 |
